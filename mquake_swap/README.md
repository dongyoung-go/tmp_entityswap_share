# MQuAKE Counterfactual Generator

Generates counterfactual variations of MQuAKE instances by replacing entities in fact chains with similar alternatives from Wikidata while maintaining multi-hop reasoning structure.

## Installation

```bash
pip install requests tqdm datasets
```

## Setup

### Download Dataset

First, download the MQuAKE-Remastered dataset from Hugging Face:

```bash
python3 data/load_hf_dataset.py
```

This will download the dataset and save it to `./data/MQuAKE-CF-3k-remastered.json`.

### Build Relation Labels

Generate the relation labels mapping by querying Wikidata:

```bash
python3 prompts/build_relation_labels.py
```

This creates `relation_labels.json` in `prompts/templates/` with human-readable labels for all property IDs used in the templates.

## Configuration

Edit `config.json` with your settings:

```json
{
  "wikidata": {
    "endpoint": "https://query.wikidata.org/sparql",
    "user_agent": "MQuAKE-CF-Generator/1.0",
    "rate_limit_delay": 0.5,
    "cache_dir": "./cache/wikidata",
    "timeout": 30
  },
  "generation": {
    "variations_per_instance": 5,
    "max_retries": 3,
    "min_similarity_score": 0.7
  },
  "data": {
    "input_path": "./data/MQuAKE-CF-3k-remastered.json",
    "output_path": "./data/MQuAKE-CF-3k-remastered-variations.json",
    "template_dir": "./prompts/templates/",
    "sample_limit": null
  }
}
```

## Template Files

Three template files in `prompts/templates/`:

**question_templates.json**
```json
{
  "P27": "What is the country of citizenship of [X]?",
  "P35": "Who is the head of state of [X]?",
  "P36": "What is the capital of [X]?"
}
```

**cloze_templates.json**
```json
{
  "P27": "[X] is a citizen of",
  "P35": "The head of state of [X] is",
  "P36": "The capital of [X] is"
}
```

**relation_labels.json** (generated by `build_relation_labels.py`)
```json
{
  "P27": "country of citizenship",
  "P35": "head of state",
  "P36": "capital"
}
```
This file maps property IDs to human-readable labels and is automatically generated from Wikidata.

## Usage

Basic usage:
```bash
python3 generate_counterfactuals.py
```

With options:
```bash
python3 generate_counterfactuals.py --sample-limit 100 --variations 10 --output data/MQuAKE-CF-test-100-10.json
```

### Command-Line Options

- `--config CONFIG_PATH` - Path to configuration file (default: config.json)
- `--sample-limit N` - Limit number of instances to process
- `--variations N` - Number of variations per instance (overrides config)
- `--output OUTPUT_PATH` - Output file path (overrides config)

## Output

Generated files:
- Main output JSON with counterfactual variations
- `generation_stats.json` - Generation statistics
- `generation.log` - Detailed logs
